## The transformer block is the engine inside every modern LLM

A transformer is a stack of identical blocks. Each block has two jobs: attention (tokens talk to each other) and a feed-forward layer (each token processes what it learned). This repeats across many layers -- GPT-4 has 96 layers, each refining the vectors further before the final output.

## Attention lets every token ask a question about every other token

For each token, the model creates three vectors from its embedding: a Query (what am I looking for?), a Key (what do I offer?), and a Value (what should I contribute if selected?). The token compares its Query against every other token's Key to get a score, turns those scores into weights with softmax, then blends all the Values using those weights. The result is a new vector for that token -- one that now carries context from the whole sequence.

### Q, K, V is a learned search engine

Think of it like a YouTube search. Your search query is Q. Each video's title is a K. The video itself is V. Attention compares your Q against every K, scores the matches, and returns a weighted blend of the matching Vs. The key difference from a real search engine: the weights are soft -- every token contributes something, just with different amounts.

### Multi-head attention runs this process in parallel

A single attention pass captures one type of relationship. Multi-head attention runs several passes in parallel -- each head learns to focus on different patterns like subject-verb, pronoun-reference, or position. The outputs are concatenated and projected back to the original dimension. Most modern models use 12 to 96 heads per layer.

<SessionSection id="practical-example" label="Practical Example">

## Why "she" in a sentence gets resolved correctly

A developer builds a document summarizer. The model receives: "The contract was signed by the CEO because she approved it." The pronoun "she" needs to resolve to "CEO" not "contract". Attention handles this -- "she" produces a Query that scores highly against the Key of "CEO" and low against "contract". The updated vector for "she" carries the CEO's context. Without attention, the model would have no mechanism to link pronouns to their referents across long distances.
