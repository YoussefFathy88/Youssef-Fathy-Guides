System Prompt — The Instructions You Never See

What you never see is doing all the work

Every time you open ChatGPT, Cursor, or any AI chat product, there is already text in the conversation — text that was put there by the developer before you arrived. It shapes the AI's name, personality, rules, and output style. You never see it, but it shapes every single answer. This session lifts the curtain.

The same model, three different jobs — just from three different system prompts

ChatGPT, Cursor, and a hospital chatbot all run on large language models. What makes them feel completely different is the system prompt written by each product's developers. The model's weights never change — only the instructions do.

Same model, different system prompt — completely different AI

Cursor AI — coding assistant

  • Role: senior software engineer embedded in VS Code
  • Task: read the file the user has open, fix bugs, write tests
  • Rules: never suggest libraries not already in package.json; explain code changes inline
  • Format: reply in the editor as code comments or diff patches

Hospital chatbot — patient triage

  • Role: HealthFirst patient intake assistant
  • Task: collect symptom information and direct patients to the right department
  • Rules: never give a diagnosis; always recommend calling 911 if the user describes chest pain
  • Format: short sentences, no jargon, reassuring tone

What we covered

System promptDeveloper-written text placed at the very top of every conversation, read by the AI before the user's first message
RoleThe section of a system prompt that gives the AI its name, job title, and employer persona
TaskThe section that tells the AI which problems it should solve and what to focus on
RulesHard limits and guardrails that override the model's default behaviour — no diagnosis, redirect competitors, stay brief
FormatInstructions that control how the AI writes — tone, length, emojis, and structure
