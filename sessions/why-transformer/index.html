What we covered

NN as a mapping functiony = mx + c: a neural network learns weights (m, c) so that inputs map to correct outputs.
Fixed window (CNN)Sees only N consecutive tokens; any word outside that window is invisible — great for images, limited for long text.
Translation invarianceA CNN filter detects the same pattern wherever it appears in an image — the core reason CNNs dominated computer vision.
Recurrent hidden state (RNN)A single vector h updated at every step; earlier tokens fade as new ones overwrite it.
Vanishing memoryAfter many steps h retains almost no signal from distant tokens — 'Egypt' is ~10% present by the time the model reads 'its'.
Self-attention (Transformer)Every token computes scores against every other token in one parallel operation — distance has no cost.
Why Transformers wonThey replaced sequential bottlenecks with direct, parallel, distance-independent token interactions.
