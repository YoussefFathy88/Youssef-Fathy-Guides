## The box runs in a loop — that's how you get a full answer

<AutoregressiveDemo
  title="Inference: a full Q&A generated token by token"
  question="What is the capital of France?"
  contextPrefix="The capital of France is"
  tokens={["Paris", ",", " which", " is", " also", " France", "'s", " largest", " city", "."]}
  topCandidates={[
    { step: 0, candidates: [{ token: "Paris", prob: 0.91 }, { token: "Lyon", prob: 0.04 }, { token: "a", prob: 0.02 }] },
    { step: 1, candidates: [{ token: ",", prob: 0.65 }, { token: ".", prob: 0.20 }, { token: " and", prob: 0.08 }] },
    { step: 2, candidates: [{ token: " which", prob: 0.48 }, { token: " a", prob: 0.22 }, { token: " the", prob: 0.15 }] },
  ]}
/>

Every word you see is one more trip through the box: the prompt so far goes in, one token comes out, that token gets appended, and the box runs again. To go from a single next-token prediction to this full loop, we need to look inside the box. Let's call this the **LLM Pipeline**.

</SessionSlide>

## What we covered

<RecapTable
  rows={[
    { term: "Mapping function", definition: "Any AI model, from y = mx + c to an LLM, maps an input to an output using learned parameters." },
    { term: "Autoregressive loop", definition: "The model generates one token at a time, feeding each new token back in to predict the next — tokenize, embed, attend, predict, repeat." },
    { term: "RAG (Retrieval-Augmented Generation)", definition: "Grounding a frozen model in your own documents by retrieving the most relevant chunks at query time instead of guessing or stuffing the whole doc into the prompt." },
    { term: "Tool schema", definition: "A structured definition (name, description, input_schema) that tells the model exactly what a function does and what arguments it needs." },
    { term: "Agent loop", definition: "The repeating cycle of reason → pick tool → execute → return result that lets an agent process many requirements, not just answer one question." },
  ]}
