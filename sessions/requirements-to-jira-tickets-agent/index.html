What we covered

Mapping functionAny AI model, from y = mx + c to an LLM, maps an input to an output using learned parameters.
Autoregressive loopThe model generates one token at a time, feeding each new token back in to predict the next — tokenize, embed, attend, predict, repeat.
RAG (Retrieval-Augmented Generation)Grounding a frozen model in your own documents by retrieving the most relevant chunks at query time instead of guessing or stuffing the whole doc into the prompt.
Tool schemaA structured definition (name, description, input_schema) that tells the model exactly what a function does and what arguments it needs.
Agent loopThe repeating cycle of reason → pick tool → execute → return result that lets an agent process many requirements, not just answer one question.
