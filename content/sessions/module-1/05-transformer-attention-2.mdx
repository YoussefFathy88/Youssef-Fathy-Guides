## The GPT Decoder: building context without looking ahead

Modern LLMs like GPT use a **decoder-only** architecture. Instead of an encoder building memory and a decoder reading it, a single stack of **decoder blocks** processes the text autoregressively.

<TransformerSubstackExplorer
  variant="decoder"
  title="Decoder block — mask, attend, refine"
  layerCount={6}
  minimal
/>

## Masked Self-Attention

During generation, a model must predict the next token based *only* on previous tokens. If it could "see" the answer in its own context window, it wouldn't learn to predict. **Causal masking** forces the model to only look backward.

## What we covered

<RecapTable
  rows={[
    {
      term: "Masked self-attention",
      definition: "In the decoder, each position may only attend to itself and earlier positions, preventing information leakage from future tokens."
    },
    {
      term: "Decoder-only architecture",
      definition: "A model design (like GPT) that relies entirely on a stack of decoder blocks to process context and generate text, without a separate encoder."
    },
    {
      term: "Autoregressive generation",
      definition: "The model predicts one token at a time, appends it to context, and repeats until an end condition is met."
    },
    {
      term: "Logits and softmax",
      definition: "A linear layer outputs raw vocabulary scores (logits), and softmax converts them to a probability distribution for token selection."
    },
    {
      term: "Training-inference alignment",
      definition: "Causal masking ensures decoder training constraints match runtime constraints, so behavior transfers reliably to real generation."
    }
  ]}
