## Trace a sentence from raw text to the predicted next token

Every LLM you use — GPT, Claude, Gemini — runs on the Transformer. The previous session explained why recurrent bottlenecks broke at scale; this one is the full 2017 *Attention Is All You Need* machine: how order is injected, how encoder and decoder stacks talk through attention, and how logits become the next token.

By the end, you can follow one sentence through tokenization, embeddings, positional encoding, encoder and decoder stacks, and the final vocabulary scores — and know why each stage exists.

The lesson path in **Core Concepts** follows that pipeline: **positional encoding**, then **one encoder layer** and **one decoder layer** as interactive stacks, then **self-attention** (Q/K/V), and finally the **full pipeline** walkthrough that ties everything together.

</SessionSection>

<SessionSection id="recap" label="Recap">

## What we covered

<RecapTable
  rows={[
    {
      term: "Self-attention",
      definition: "Each token builds Q, K, and V vectors, scores all keys with its query, softmaxes the scores, and blends the values — producing one context-aware output vector per token."
    },
    {
      term: "Masked self-attention (decoder)",
      definition: "In the decoder, each position may only attend to itself and earlier positions so the model cannot peek at future tokens while generating left-to-right."
    },
    {
      term: "Multi-head attention",
      definition: "8 independent attention heads run in parallel on 64-dim slices of the input, then concatenate and project — capturing 8 different relationship types in one layer."
    },
    {
      term: "Positional encoding",
      definition: "Sine and cosine vectors computed from each token's position index, added to its embedding so the model knows word order despite reading all tokens at once."
    },
    {
      term: "Residual connection",
      definition: "The sub-layer's input is added to its output before normalization, preserving the original signal across all 6 stacked layers so nothing is lost during deep training."
    },
    {
      term: "Cross-attention",
      definition: "The decoder's attention mechanism where Queries come from the decoder's own state but Keys and Values come from the encoder output — the bridge that grounds generation in the source."
    }
  ]}
/>
