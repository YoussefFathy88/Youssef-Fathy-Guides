A mid-sized React + Node.js project: 400 files, ~1,800 functions, ~180,000 lines. The total codebase is roughly 750,000 tokens. No AI tool can fit this in one context window — so it is never sent whole.

What we covered

TokenThe basic unit the model processes — roughly 1 token per common English word, more for code, URLs, and non-English text
Byte-Pair EncodingTokenization algorithm that splits text into frequent subword patterns learned from training data
Token IDThe integer that maps a token to its position in the model's vocabulary — the only thing the model actually operates on
Context windowThe maximum number of tokens a model can process in a single call — GPT-4o supports 128k tokens, Claude Sonnet 4 supports 200k, Gemini 1.5 Pro up to 1M
CompactA compression command (e.g. /compact in Claude Code) that summarises the entire conversation history into a short handoff block, resetting the token count while preserving full working continuity
System promptHidden instructions the platform sets before your first message — defines the model's persona, rules, and capabilities. Always consumes tokens even though you never see it
