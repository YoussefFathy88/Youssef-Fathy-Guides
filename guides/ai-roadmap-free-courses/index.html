Getting Started with AI: A Free Course Roadmap

Oct 24, 2026 · Youssef Mohamed Fathy

A simple path to learn AI for free with courses from OpenAI and Anthropic. Learn the basics of ChatGPT or Claude, start building with a coding agent, then learn fastest by trying real use cases.

RoadmapChatGPTClaudeCodexClaude CodeFree Courses

Why this roadmap

You can do a lot with just ChatGPT or Claude: build websites and apps, edit videos, and speed up your daily work.

The companies that make them both run free academies:

  • OpenAI Academy: courses for ChatGPT and Codex.
  • Claude Academy: courses, tutorials, and use cases for Claude and Claude Code.

You don't need both. Pick the tool you already use and follow the three steps below.

StepGoal
1. Learn the basicsUse ChatGPT or Claude well for everyday work
2. Build with AIMake websites, apps, and tools with a coding agent
3. Learn by doingTry real use cases, then apply them to your own work

Step 1: Learn the basics

If you use ChatGPT

Open OpenAI Academy courses and go to Apply AI at Work. Pick your level:

Your levelCourseWhat you learn
New to AIAI FoundationsThe basics of AI and ChatGPT: clear instructions, useful context, checking answers
Some experienceApplied AI FoundationsTurn a task you repeat into a step-by-step workflow
Comfortable with AIAgents and WorkflowsGuide AI agents through structured work and reuse what works

If you use Claude

Open Claude courses:

  1. Start with Claude 101: your first chat, good prompts, projects, artifacts, and skills.
  2. Then take AI Fluency: Framework and foundations to learn how to work with AI well and safely.
  3. Check back often. New courses are added as Claude gets new features.

Step 2: Build with AI

You don't need to be a developer to start. A coding agent writes the code for you. Your job is to explain what you want and check the result.

ToolMade byStart with
CodexOpenAIGet Started with Codex
Claude CodeAnthropicClaude Code 101, then Claude Code in action
  • Codex courses: OpenAI Academy, under Build with AI.
  • Claude Code courses: Claude Code courses.
  • Prefer live sessions? Claude Academy also runs a recurring Claude Code: Foundations webinar.

Step 3: Learn by doing (my favorite)

Courses are good. Trying real examples is better. When you see what other people build, you get ideas for your own work.

  • Claude tutorials: short how-to lessons.
  • Claude use cases: real tasks you can try in Claude.
  • All use cases: filter by your job, like Marketing, HR, Finance, Engineering, or Design.

How to use a use case

  1. Pick one that is close to a task you do every week.
  2. Follow it once, step by step.
  3. Do it again with your own real work.
  4. Keep the prompt that worked, so next time is faster.

Tips before you start

  • One tool first. Finish Step 1 with one tool before you try the other.
  • Apply it the same week. After each course, use what you learned on one real task.
  • Courses are free, tools may not be. Some features, like coding agents, can need a paid plan. Check the pricing page before you start.
