## From raw API calls to an agent that manages tasks

The RAG lab gave the model memory. This lab gives it hands. You will build an AI task manager where the model can create, update, prioritise, and complete tasks — using real function calls backed by a database. Before writing code, this session walks the three conceptual steps that make it possible: the bare API call, schema-constrained output, and tool-augmented action.

</SessionSection>
