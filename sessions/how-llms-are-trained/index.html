How do you know the model actually worked?

You trained the model. But how do you know if it actually worked?

After pretraining: ✅ Model can predict text

After SFT: ✅ Model follows instructions

After RLHF/DPO: ✅ Model is aligned

After evaluation: ❓ But is it actually good?

Does it know facts correctly?

Does it tell the truth or hallucinate?

Can it write working code?

Without evaluation you're just guessing. Evaluation gives you a measurable answer.

Same prompt — three training checkpoints

Prompt

I have a headache and fever. What medicine should I take?

Base Model (Pre-training only)

Response will appear here…

Pre-training only taught the model to continue text. It has no concept of a question — so it continues the sentence like a health blog article, not a helpful answer.

Instruct Model (After SFT)

Response will appear here…

SFT taught the model to answer questions directly. It gives a confident, specific dose — but has no safety guardrail. It doesn't know the person's age, allergies, or medical history.

Aligned Model (After DPO)

Response will appear here…

RLHF / DPO taught the model that helpful medical answers must be safe. It avoids a specific dose, explains why, gives general options, and tells the user when to see a doctor.
